# Humanoid Guide Contract

## Purpose

Define the user-facing and maintainer-facing contract for evolving the current CMD guide
into a more humanoid portfolio mascot.

## Visitor Contract

1. The guide still reads as the same CMD-inspired corner companion already present in the
   portfolio.
2. The guide may show simple humanoid cues and a lightweight greeting gesture that make it
   feel warmer.
3. Interacting with the guide still reveals the same category of short prompt or hint.
4. The portfolio remains fully usable without interacting with the guide.

## Maintainer Contract

1. The feature remains a visual redesign of the existing guide, not a new assistant
   product.
2. The CMD identity must remain visible even after humanoid details are added.
3. Theme behavior must remain coherent in both light and dark modes.
4. Gesture motion must stay reduced-motion-safe, non-blocking, and visually secondary.

## Non-Goals Covered by This Contract

- Replacing the guide with a fully different mascot
- Adding new prompt flows or assistant capabilities
- Introducing backend-driven behavior or personalization
- Making the guide a required navigation path
- Adding large or cinematic character animation sequences

## Verification Cues

- A reviewer can still identify the guide as the same CMD avatar at first glance.
- A reviewer can perceive simple humanoid traits and at least one friendly greeting
  gesture.
- A reviewer can trigger the prompt and confirm the interaction model still matches the
  existing guide pattern.
- A reviewer can switch themes and confirm the guide remains legible and secondary.
